# MyChat

聊天 App 的可运行前身项目。
框架已验证，Kotlin 阶段负责移植。

## 开始

mychat.py 选 1 打包
打开 dist/mychat-demo.html

## 目录

- ARCHITECTURE.md 权威规范
- HANDOFF.md 交接说明
- CURSOR.md 分批清单
- ui/shell.html 外壳
- js/ 运行时与测试
- modules/ 模块包
- docs/ 设计稿
- dist/ 产物
- legacy/ 旧工程归档

## 规矩

1 改完 js 或 modules 要重新打包
2 dist 里是产物不要手改
3 legacy 只作参考
